# Задача 4: Расширение функционала AI агента

Расширение агента из задачи 3 продвинутыми механизмами: структурированный вывод, динамическая система навыков и интеграция внешних инструментов через MCP.

---

## Что добавляется

### 1. JSON Structured Output

Вместо свободного текста агент возвращает строго типизированный объект по Pydantic-схеме.

```python
class AgentResponse(BaseModel):
    result: str
    confidence: float          # 0.0–1.0
    reasons: list[str]
    risk_level: Literal["НИЗКИЙ", "СРЕДНИЙ", "ВЫСОКИЙ"]
    analysis_type: list[str]   # какие skills были применены
```

`llm.with_structured_output(Schema)` использует function calling: LLM гарантированно возвращает корректный JSON, который десериализуется в Python-объект. Такой вывод удобен для API — ответ агента сразу готов к передаче клиенту без парсинга текста.

### 2. Skills — вариативные мини-промпты

Skills — короткие текстовые блоки, которые добавляются в системный промпт **динамически** в зависимости от запроса пользователя.

```
Базовый промпт (всегда)
  + Skill A  ← подключается если нужен
  + Skill B  ← подключается если нужен
```

Определение нужных Skills происходит автоматически по ключевым словам, или Skills передаются явно. Такой подход позволяет:

- держать базовый промпт коротким
- подключать специализированные инструкции точечно
- добавлять новые навыки без переписывания агента

### 3. MCP-сервер (примеры в `examples/`)

MCP (Model Context Protocol) — открытый стандарт Anthropic для подключения LLM к внешним данным и инструментам.

```
LLM Agent  <──MCP──>  MCP Server (БД, API, файлы...)
```

В `examples/mcp.ipynb` показано, как поднять MCP-сервер с набором инструментов и подключить его к агенту через `langchain-mcp-adapters` — без изменения кода самого агента.
