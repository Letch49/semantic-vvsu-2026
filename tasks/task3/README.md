# Задача 3: LangChain-агент

## Описание

Реализовать специализированного чат-агента на базе `langchain` + `groq`. Агент должен решать задачи в одной узкой предметной области, корректно отклонять запросы вне своей компетенции и быть доступен через мини-сервис.

---

## Что нужно сделать

### 1. Выбрать специализацию агента

Выберите одну роль (или предложите свою):

| # | Роль | Примеры задач |
|---|------|---------------|
| 1 | Фитнес-тренер | составить программу тренировок, рассчитать КБЖУ |
| 2 | Инвестиционный советник | анализ акций, рекомендации по портфелю |
| 3 | Юридический помощник | объяснить статью закона, составить претензию |
| 4 | Маркетолог | идеи для постов, анализ ЦА, рубрикатор |
| 5 | Тестировщик | сгенерировать тест-кейсы, найти баги в коде |
| 6 | Планировщик | декомпозиция задачи, оценка сроков |
| 7 | Любая другая роль | по согласованию с преподавателем |

### 2. Реализовать агента

- **Системный промпт** — роль, ограничения, стиль ответа
- **User-промпт** — шаблон обращения к агенту
- **Обработка неизвестных команд** — если запрос не по теме, агент отвечает: `"Команда неизвестна"`
- **LLM** — использовать `ChatGroq` из `langchain-groq`

### 3. Подключить инструменты (skills)

Добавить **минимум 2 инструмента** (`@tool`), которые агент вызывает автоматически. Примеры:

- поиск информации (Wikipedia, DuckDuckGo)
- калькулятор / формульные расчёты
- работа с CSV / базой данных
- получение данных из внешнего API

### 4. Реализовать мини-сервис

Сделать REST API на FastAPI с эндпоинтом `POST /generate`, который принимает сообщение и возвращает ответ агента. В качестве альтернативы — бот в мессенджере.

## Технические требования

Стек: `langchain`, `langchain-groq`, `langchain-community`, `fastapi`, `uvicorn`, `python-dotenv`.

Переменную `GROQ_API_KEY` хранить в `.env` файле, не хардкодить в коде.

Структура сдачи:

```
task3-solution/
├── agent.py
├── app.py
├── .env.example
└── report.md
```

## Критерии оценки (10 баллов)

| Баллы | За что |
|-------|--------|
| 2 | **Качество кода**: читаемость, структура, отсутствие лишнего кода |
| 2 | **Системный промпт**: точная специализация, правила поведения, стиль |
| 2 | **Подключаемые skills**: минимум 2 работающих инструмента |
| 2 | **Мини-сервис**: работающий REST API или бот |
| 2 | **Обработка неизвестных команд**: агент отвечает `"Команда неизвестна"` на нерелевантные запросы |
